# Surya Beer Storefront

A pixel-perfect, clean beer storefront built **100% purely with HTML5 and CSS3** (Zero JavaScript, all styles inlined into `index.html`).

## Project Structure

```
├── index.html        # Complete Single HTML file with all CSS inlined
└── assets/           # Images and graphics (Bottles, hops, lemon)
```

## How to Run

Simply double-click or open `index.html` in any web browser.
